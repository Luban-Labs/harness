# 本会话记录 详情

## 边界与取舍
- **为什么只信调度器传来的 DSH 日志路径,不重扫 `~/.dsh/sessions/`**:按 DSH 协议主/子日志归属由调度器裁定,Stop 重扫磁盘可能撞到同 ID 多目录或失效索引;只校验传入路径的 v4 header `id` 与 `parentSession` 闭合链,链断即丢弃。
- **为什么纳入 `subagents/` 却排除独立外部进程**:子代理在同一会话授权下替当前会话写代码,必须算入本会话证据;但没有挂载为子记录的独立 `codex exec` / 并发会话不在内,宁可漏报也不把旁路改动算成当前会话。
- **为什么只读新近片段**:长会话日志可达数百 MB,按尾部字节上限截断读取,避免拖垮 Stop 时延预算。
