# 核心判断

本表登记被两处以上用来做决定的判断、业务数、限制或保护,每节一张 ≤300 字索引卡;规则见 docs/rules/harness.md「核心判断只写一份」。用 `python3 .claude/hooks/judgments.py` 按需查(`ls`、`show <名>`、`show <名> --detail`、`check`),不整表读进上下文。每节以 `## <概念名>` 开头,下列定义、唯一实现、语义例外、待收口四项(没有写「无」),需要时末尾加「详情」。

<!-- 以上是空表:init 与迁移只建到这一行之前。以下是格式说明与示例,不抄进项目。 -->

格式:每个概念用一个二级标题 `## <概念名>`,一节合计 ≤300 字(按字符数算);项目有 CONTEXT.md 的,概念名沿用其中的词。节内禁写「出处:」与 `MM-DD` 日期(出处、事故进 spec「不做」、`docs/decisions.md` 或提交信息)。标题下各项:

- 定义:一句,≤120 字。
- 唯一实现:只许反引号包住的项目根相对 `路径:函数名`、`路径:类名` 或 `路径:类名.方法名` 加分隔符(不写行号、不夹说明),或「待定」。
- 语义例外:名字与理由,每项一行 ≤120 字;没有写「无」。
- 待收口:还在用的副本与计划,每项一行 ≤120 字;没有写「无」。
- 详情:可选,`docs/judgments/<概念名>.md`(只写代码看不出的边界、为什么不那样做、容易踩的坑;没有不需要写这一行)。

空表只有开头那段说明,没有二级标题;登记第一个概念时接在说明后面写。

示例(虚构的「同区」):

```md
## 同区
- 定义:两个区名指场馆里同一块区域。
- 唯一实现:`src/sections.py:same_section`
- 语义例外:比价的「同层」另叫 `same_tier`,相邻区算同层(仅比价展示用)
- 待收口:`src/legacy.py:match_section` 只比数字,计划下个任务切到 `same_section`
- 详情:`docs/judgments/同区.md`
```
