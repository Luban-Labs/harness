# 核心判断

本表登记被两处以上用来做决定的判断,每个概念一节,写明唯一实现;规则见 docs/rules/harness.md「核心判断只写一份」。每节以 `## <概念名>` 开头,下列定义、唯一实现、语义例外、待收口四项,没有的写「无」。

<!-- 以上是空表:init 与迁移只建到这一行之前。以下是格式说明与示例,不抄进项目。 -->

格式:每个概念用一个二级标题 `## <概念名>`,概念名沿用 CONTEXT.md 的词。标题下四项:

- 定义:一句。
- 唯一实现:模块与函数名,不写行号。
- 语义例外:名字与理由;没有写「无」。
- 待收口:还在用的副本、差在哪、计划;没有写「无」。

空表只有开头那段说明,没有二级标题;登记第一个概念时接在说明后面写。

示例(虚构的「同区」):

```md
## 同区
- 定义:两个区名指场馆里同一块区域。
- 唯一实现:<模块.函数>
- 语义例外:比价的「同层」另叫 <名字>,相邻区算同层(理由:……)
- 待收口:<副本位置> 只比数字,北看台 1 和南看台 1 会判成同区;计划:……
```
